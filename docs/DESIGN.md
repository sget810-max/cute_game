# そらのはこにわ 企画メモ

## コンセプト
空に浮かぶ小さな島に、草や花や水たまりを置いていく。
組み合わせによって、ふしぎな精霊がやってきて住みつく。
**失敗がない・急かされない・眺めているだけで楽しい** 箱庭ゲーム。

- 対象: スマホ(縦画面・指1本)
- 見た目: パステル、まるいフォント、やわらかい影
- 1回のプレイ: 数十秒〜数分。開いて眺めて閉じる、を何度でも

## 基本の遊び方
1. 下の道具バーからアイテムを選ぶ(くさ/おはな/いし/みず/きのこ/き/けす)
2. 島のマスをタップ(なぞると連続で置ける)
3. 条件がそろうと「なにかの気配がする…」→ 数秒後に精霊がやってくる
4. 精霊をタップすると、ぴょんと跳ねてひとこと話す(寝ていたら起きる)
5. 図鑑で、会った精霊と未発見の精霊のヒントを確認

## 時間と天気
- 5分で昼 → 夕方 → 夜 → 朝 とひとめぐり(左上のボタンで次まで何秒か分かる)
- 1分ごとに25%の確率で雨
- 夜は星とほたるが出て、昼の精霊は眠りやすくなる

## 精霊(10種)
| 名前 | 条件 | ひとこと |
|---|---|---|
| もこ | くさ3つ以上 | 草のにおいが好き |
| ぽわ | おはな3つ以上 | 花びらの精霊 |
| ころん | いし2つ・くさ2つ以上 | ひなたぼっこ |
| しずく | みず2つ以上 | 水たまりで遊ぶ |
| きのぴ | きのこ2つ・き1本以上 | はずかしがりや |
| そよ | き3本・おはな2つ以上 | ちょっと浮いている |
| あまつぶ | 雨の日 + みず1つ以上 | かさがお気に入り |
| つきみ | 夜 + おはな2つ・いし1つ以上 | 夜にしか会えない |
| ぽっ | 夜 + みず1つ・くさ3つ以上 | ほたるの精霊 |
| にじ | 精霊5種以上が住んでいる昼 + みず・おはな | とてもめずらしい |

条件がくずれると、しばらくして「おさんぽに出かけた」などと言って去る(図鑑には残る)。

## 音
- 置くたびにペンタトニックの「ぽろん」
- ときどき鳴る風鈴のような音、雨の日は雨音
- 右上で音のオン/オフ

## 技術
- `index.html` 1枚(HTML + CSS + Canvas 2D + Web Audio)。外部ライブラリなし
- セーブは localStorage(島の配置、図鑑、音の設定)

## 今後のアイデア
- 精霊どうしの仲よしイベント(特定の2匹がそろうと一緒に遊ぶ)
- 季節(桜・ひまわり・紅葉・雪)とそれぞれの限定精霊
- 島を広げる / 2つ目の島
- 精霊からの小さなおくりもの(放置していると何か置いてある)
- 写真モード(UIを隠してスクショ)
- ホーム画面に追加できるPWA化
